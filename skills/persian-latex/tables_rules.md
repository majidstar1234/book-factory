# قواعد جدول‌ها

## الگوی مرجع LaTeX
نمونهٔ تأییدشده از محیط‌های LaTeX زیر استفاده می‌کند:
- `table` و `tabular`
- `\caption` و `\label`
- `\toprule`، `\midrule` و `\bottomrule`
- ستون‌های هم‌تراز و سلول‌هایی که فارسی، نام لاتین و مقدار عددی دارند.

این الگو برای نمونهٔ مستقیم LaTeX تأیید شده است.

## پشتیبانی آزموده‌شده در مبدل فعلی
`scripts/build_book.py` جدول سادهٔ Markdown با سطر جداکنندهٔ استاندارد را به محیط `tabular` تبدیل می‌کند. آزمون یکپارچه با XeLaTeX و قالب پروژه موفق شده است.

قواعد و محدودیت‌ها:
- تعداد سلول‌های عنوان، سطر جداکننده و هر ردیف داده باید یکسان باشد؛ ناسازگاری با `ValueError` روشن متوقف می‌شود.
- سلول‌ها باید تک‌خطی باشند.
- پشتیبانی از pipe فرار داخل سلول، سلول چندخطی، عنوان/برچسب Markdown، ادغام سلول‌ها و جدول‌های عریض تضمین نشده است.
- تبدیل فعلی از کادر سادهٔ `tabular` با خطوط افقی استفاده می‌کند؛ قالب پیشرفتهٔ `booktabs` از Markdown تولید نمی‌شود.
- جهت و ظاهر بصری جدول همچنان باید در PDF بررسی شود؛ موفقیت کامپایل به‌تنهایی تأیید راست‌به‌چپ بودن نیست.
- در خروجی Markdown فرمان‌های خام `tabular` و `booktabs` وارد نکن.

## معیارهای پذیرش
1. تعداد سلول‌های هر ردیف با تعریف ستون‌ها سازگار باشد.
2. متن فارسی، نام انگلیسی و عدد در PDF خوانا باشند.
3. جهت جدول و ترتیب ستون‌ها در خروجی بصری بررسی شود.
4. جدول‌های عریض فقط پس از آزمون راهکار مناسب استفاده شوند.
5. آزمون تبدیل و کامپایل روی نمونهٔ کوچک انجام شود.
