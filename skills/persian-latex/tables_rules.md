# قواعد جدول‌ها

## الگوی مرجع
نمونهٔ تأییدشده از محیط‌های LaTeX زیر استفاده می‌کند:
- `table` و `tabular`
- `\caption` و `\label`
- `\toprule`، `\midrule` و `\bottomrule`
- ستون‌های هم‌تراز و سلول‌هایی که فارسی، نام لاتین و مقدار عددی دارند.

این الگو فقط برای LaTeX مستقیمِ نمونه تأیید شده است.

## محدودیت مبدل فعلی
`scripts/build_book.py` در نسخهٔ بررسی‌شده تبدیل اختصاصی برای جدول Markdown ندارد. پس وجود جدول در متن ورودی به معنی تبدیل صحیح آن به LaTeX نیست.

## قرارداد تا زمان اصلاح مبدل
- جدول را فقط وقتی پیشنهاد کن که خوانایی را بهتر کند.
- جدول‌های Markdown را به‌عنوان قابلیت تضمین‌شده فرض نکن.
- برای محتوای ساده، فهرست یا بندهای مقایسه‌ای را ترجیح بده تا وقتی آزمون جدول موفق شود.
- فرمان‌های `tabular` و `booktabs` را در خروجی Markdown خام وارد نکن.

## معیارهای پذیرش جدول در آینده
1. تعداد سلول‌های هر ردیف با تعریف ستون‌ها سازگار باشد.
2. عنوان و برچسب یکتا باشند.
3. متن فارسی، نام انگلیسی، عدد و فرمول در PDF خوانا باشند.
4. جهت جدول و ترتیب ستون‌ها در خروجی بصری بررسی شود.
5. جدول‌های عریض در اندازهٔ صفحه جا شوند یا راهکار شکست/چرخش آن‌ها آزموده شده باشد.
6. آزمون تبدیل و کامپایل روی نمونهٔ کوچک و نمونهٔ مرجع انجام شود.
