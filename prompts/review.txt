فصل زیر را مانند یک ویراستار ارشد فنی بررسی کن.

عنوان: {chapter_title}

متن فصل:
{chapter_content}

فقط JSON معتبر برگردان و هیچ متن دیگری قبل یا بعد آن ننویس:
{
  "approved": true,
  "score": 0,
  "summary": "...",
  "issues": [
    {"type": "accuracy|structure|language|duplication|unsupported_claim", "severity": "low|medium|high", "description": "..."}
  ],
  "revision_instructions": ["..."]
}

قواعد امتیاز:
- 90 تا 100: آماده انتشار
- 75 تا 89: قابل انتشار با اصلاحات جزئی
- کمتر از 75: نیازمند بازنویسی
- اگر مسئله مهم علمی/فنی وجود دارد approved=false باشد.
علاوه بر معیارهای محتوایی بالا، سازگاری فصل با خط تولید را نیز بررسی کن:
- خروجی باید از Markdown ساده‌ای استفاده کند که مبدل فعلی پشتیبانی می‌کند.
- جدول سادهٔ Markdown مجاز است؛ تعداد سلول‌های عنوان، جداکننده و ردیف‌ها را بررسی کن و جدول چندخطی یا پیچیده را خطر ساخت خروجی گزارش کن. فرمان خام LaTeX، `\\lr{...}`، محیط equation، شکل یا ارجاع LaTeX را در صورتی که پشتیبانی آزموده‌شده ندارند، به‌عنوان خطر گزارش کن.
- یکدستی اصطلاحات انگلیسی، ارقام فارسی، اعشار، واحدها و نمادهای ریاضی را بررسی کن.
- اگر موردی به بررسی PDF نیاز دارد، آن را صریحاً در issues یا revision_instructions بنویس؛ ادعا نکن که ظاهر PDF از روی متن به‌تنهایی تأیید شده است.
- در صورت وجود ایراد جدی سازگاری که احتمال شکست ساخت یا خرابی محتوای خروجی را ایجاد می‌کند، approved=false بده و راهکار اصلاح مشخص ارائه کن.
